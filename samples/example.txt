Система контроля версий хранит историю изменений проекта.
Каждый коммит фиксирует состояние файлов и сообщение автора.
Ветки позволяют вести параллельную разработку без помех друг другу.
Слияние веток объединяет результаты работы в общую историю.
Git работает распределённо: полная копия репозитория есть у каждого разработчика.
Модель Git flow задаёт правила для веток main, develop, feature, release и hotfix.
